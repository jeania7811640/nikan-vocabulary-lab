資料管理

CSV 使用 UTF-8 編碼，欄位包含中文、日文、假名、韓文、羅馬拼音、例句、分類與複習紀錄。匯入時會合併新詞，不會刪除現有資料。

雲端同步部署說明

本版本已加入 Supabase 登入與同步前端。部署前，必須先在 Supabase SQL Editor 執行隨附的 schema.sql，並在 Authentication 設定允許 Email 登入。公開 publishable key 可放在前端，但資料安全依賴 RLS 權限政策；絕不可將 service_role／secret key 放入 HTML。

語音使用瀏覽器內建 Speech Synthesis；可用語音取決於作業系統、瀏覽器與已安裝語音。若缺少日文或韓文語音，可能沒有聲音或使用不理想的聲線。
